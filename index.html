📋 使用规则

    🔄 更新团队数据

    本页面数据由团队成员用自己的洛谷账号抓取并提交。

    第 1 步：把下面的按钮拖到浏览器书签栏
    📌 更新洛谷团队数据
    第 2 步：打开洛谷团队页面（已登录），点击书签栏上的按钮
    第 3 步：脚本自动抓取所有分页 → 下载 data.js
    第 4 步：把 data.js 上传到 GitHub 覆盖旧文件 → 1 分钟后刷新网站
    💡 部署在 GitHub Pages 时：
    GitHub 仓库 → 点 data.js → 右上角 铅笔图标 → 全选删除 → Ctrl+V 粘贴新内容 → Commit changes。
